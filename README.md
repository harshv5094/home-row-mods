# Home Row Mods

## Linux Setup

- `curl`

```bash
curl -sL https://raw.githubusercontent.com/harshv5094/home-row-mods/refs/heads/main/linux.sh | sh 
```

- `wget`

```bash
wget -qO- https://raw.githubusercontent.com/harshv5094/home-row-mods/refs/heads/main/linux.sh | sh 
```

## Windows setup

> [!IMPORTANT]
> Install the kanata from scoop, it works compared to winget version
>
> ```ps1
> scoop install kanata
> ```

- Press `Super + R` and run `shell:startup`.
- Add the shortcut of `kanata_window_gui_winlOv2_x64.exe` in the directory opened in `shell:startup`.
